PDF to line items: text-layer extraction with OCR fallback for scanned orders, each row parsed into description, size, barcode, qty and price.

Matching: barcode first, then size plus fuzzy description with a confidence score. Low-confidence rows go to a review screen instead of silently carting the wrong product.

Wholesaler adapters: one module per wholesaler holding that customer's own encrypted login. API where one exists, headless browser session where it doesn't, so new wholesalers plug in without touching the core.

Concurrent users and caps: each comparison runs as a background job on Sidekiq/Redis so users never queue behind each other, with a quota table enforcing the weekly per-user limit.

Output: cheaper items pushed to cart, plus a printable Code128/EAN-13 barcode sheet.

What You'll Get

Rails + Postgres app, private login per customer, owner admin to add/remove customers and set their caps, two wholesalers live at launch with a documented adapter pattern for the rest, deployed with CI/CD.
